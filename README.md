# 세력의 매니저 (sepower-manager)

강회장 대신 텔레그램 채널을 운영하는 봇이다. 봇 계정은 @sepower_new_bot이고, 2026-09-17 라이브 영상 지시로 만들었다.
**PC가 꺼져 있어도 GitHub Actions에서 돈다.**

## 하는 일
1. **글감 수집** (30분마다) — 원천만 쓴다.
   - 구글뉴스 검색 19개: 가상자산 과세·클래리티·ETF·FOMC·엔비디아·HBM 등
   - 매체·공식 RSS: CoinDesk, The Block, Cointelegraph, 연준
   - 뉴스통신: 코인니스 / 데이터봇: 고래 입출금·대형 청산
   - 인플루언서 채널(에버그린·해달·박주혁 등)은 **글감으로 쓰지 않는다.** 문체만 분석해서 [STYLE.md](STYLE.md)로 정리했다.
2. **거르기** — 광고·이벤트·에어드랍, 쉴링, 채널끼리 서로 홍보하는 글, 중복 기사, 질 낮은 매체를 뺀다.
3. **고르기 + 쓰기** — `claude -p`가 한 번에 최대 2개를 고르고 STYLE.md 유형(A~F)으로 쓴다.
   - 여러 매체가 같이 다루는 이슈일수록 우선한다.
   - 음슴체, 짧게, 사진 + 한 줄 해석, 해시태그 1~2개
4. **이미지** — 기사 대표 사진 → 기사 화면 캡처 순으로 붙인다.
5. **고래/청산** — 1,000억 이상 고래 이동(거래소 내부 이동 제외), 100만 달러 이상 청산. 하루 3개/2개까지.
6. **아침 체크포인트** — 07:30 이후 첫 회차에 쓴다.
7. **발행** — 기본은 **자동 발행**이다.
   - 24시간 돈다. 보통 글은 **60~120분 무작위 간격**, 긴급 속보는 마지막 발행 15분 뒤에 바로 나간다(하루 4개까지). 하루 최대 20개.
   - 발행 채널이 **여러 곳**이면 같은 글이 모든 채널에 올라간다. 봇을 채널 관리자로 넣으면 DM으로 "여기에도 발행" 버튼이 오고, `/targets`로 목록을 보고 뺄 수 있다.
   - 올라간 글은 강회장 DM으로 사본이 오고, 🗑 버튼을 누르면 모든 채널에서 지워진다.
   - 대기열에 글이 있으면 새 초안을 쓰지 않는다. 미리 쌓아두면 시의성이 떨어지기 때문이다. 대기 글은 3시간이 지나면 폐기한다.
   - `/approve`로 바꾸면 초안마다 ✅ 올리기 / 🔁 다시쓰기 / 🗑 버리기 버튼이 온다.
8. **중복 발행 차단** — `state` 브랜치의 `published.json`(발행 장부)를 쓴다.
   - 클라우드 캐시는 옛 상태가 복원될 수 있다. 그래서 발행 직전에 장부 원격 최신본을 확인한다.
   - 같은 글, 같은 원문(기사 URL·게시물), 같은 캡처 이미지면 **절대** 다시 내보내지 않는다. 기록은 72시간 보관한다.
   - 발행 간격도 장부의 마지막 발행 시각으로 계산하므로 어느 회차든 같은 결과가 나온다.

명령어: `/status` `/targets` `/now` `/brief` `/pause` `/resume` `/auto` `/approve` `/help`

## 클라우드 구조
| 회차 | 주기 | 하는 일 | 시간 |
|---|---|---|---|
| `mode=updates` | 5분 | 버튼·명령 처리. 다시쓰기·/now·/brief가 있을 때만 claude 설치 | ~30초 |
| `mode=cycle` | 30분 | 버튼 처리 + 수집 → 초안 → DM/발행 | ~3분 |

- cron-job.org가 `workflow_dispatch`를 호출한다. GitHub `schedule`은 붐비면 건너뛰기 때문이다.
- 상태 DB는 `actions/cache`로 회차 간에 이어진다. 오래된 수집글은 3일 뒤 자동 삭제된다.
- Secrets:

  | 이름 | 내용 |
  |---|---|
  | `TELEGRAM_BOT_TOKEN_MANAGER` | 봇 토큰 |
  | `TELEGRAM_ADMIN_CHAT_ID` | 초안 받을 DM |
  | `TELEGRAM_TARGET_CHAT_ID` | 발행할 채널(쉼표로 여러 개). 이후엔 DM 버튼 목록이 우선 |
  | `CLAUDE_CODE_OAUTH_TOKEN` | `claude setup-token` (구독, API 과금 없음) |

## 로컬
```
python run.py preview       # 전송 없이 초안 미리보기 → data/preview.html
python -m unittest discover tests
```
`start.vbs`(창 없는 상시 구동)는 클라우드와 **동시에 켜면 안 된다.** 버튼을 서로 가져간다.

## 문체 출처
`tools/parse_export.py`로 에버그린 대화 내보내기를 읽었고, 참고 채널 9곳의 최근 글을 분석했다.
분석은 길이·사진 비율·목록 비율·이모지·어미 기준이다. 원문은 저장소에 넣지 않았다(`data/`는 gitignore).

## 같이 올라가는 것
`sepower384/market-briefing`의 📊 시장 보고서(3시간마다)도 같은 채널들에 올라간다.
- 설정: 그 저장소의 Secrets `TELEGRAM_CHANNEL_CHATS_BRIEF`, `TELEGRAM_CHANNEL_BOT_TOKEN`(이 봇 토큰)
- 채널 글은 봇 이름이 아니라 채널 이름으로 보이므로, 채널에 관리자로 들어가 있는 이 봇이 대신 올린다.

## 정기 보고서 (PDF → 강회장 DM)
| 종류 | 언제(KST) | 대상 기간 | 재료 |
|---|---|---|---|
| 주간 | 월요일 08시 | 지난주 월~일 | 발행 글 + 시장 데이터 |
| 월간 | 1일 09시 | 지난달 | + 주간 보고서 요약 |
| 분기 | 1·4·7·10월 1일 10시 | 지난 분기 | + 월간 보고서 요약 |
| 연간 | 1월 1일 11시 | 지난해 | + 월간 보고서 요약 |

- 30분 정기 회차가 만들 때가 됐는지 확인한다. 늦어도 3일 안이면 만회한다.
- 완료 여부는 `state` 브랜치의 `reports/done.json`, 요약은 `reports/<종류>/<키>.json`에 남는다.
- 발행 글 원문은 `archive/YYYY-MM.jsonl`에 **영구 보관**한다. 보고서 재료로 쓴다.
- 시장 데이터: BTC·ETH·SOL(CoinGecko), S&P500·나스닥·코스피·엔비디아·달러인덱스·미 10년물·금·WTI(Yahoo), 공포탐욕지수.
- 구성:
  1. 표지(힉스필드 그림 `assets/covers/`)
  2. 한눈에 보기(요약 3줄 + 지표 카드 12개)
  3. 가격 차트·자산별 수익률
  4. 핵심 이슈(주간 5 / 월간 6 / 분기 7 / 연간 8)
  5. 분야별 정리(크립토·거시·반도체AI) + 기간 흐름
  6. 체크포인트 + 세력 관점
  7. 채널 운영 기록
- 내용이 넘치면 다음 쪽으로 흐른다. 여백에 머리말과 쪽 번호가 들어간다.
- 샘플(진행 중인 기간, DM으로 전송): `gh workflow run manager.yml -f mode=report -f kind=weekly`
- PDF는 실행 결과물(artifact)로도 90일 보관한다.
